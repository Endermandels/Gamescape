# Gamescape

A local project management tool for game developers. Terminal-style UI with tree and kanban views.

## Requirements

- [Node.js](https://nodejs.org/) v18+

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

## Build a portable executable

```bash
npm run build
```

Output is placed in `release/`.

## Data

Project data is stored in `%APPDATA%\Gamescape\data\` as human-readable JSON files.
